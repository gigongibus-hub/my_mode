Одна модель, три варіанти текстури (32×32, усі на ту саму розгортку).

## Будова
Маленька кружка 4×5×4 пікселі. Модель розділена на 3 кістки (раніше була одна):
- `kruzka` — заготовка кружки (дно й стінки);
- `vuha_dla_kruzky` — вушка для ручки (дві планки зверху й знизу);
- `rucka` — ручка.

Fij поклав цей самий файл у три папки: «модель_заготовки_кружки», «модель_вух_для_ручки», «ручка_для_кружки»
(файли однакові). Схоже, задумано як етапи виготовлення: заготовка → + вушка → + ручка = готова кружка.
У GeckoLib це можна зробити однією моделлю, ховаючи кістки.

## Спитай у Fij перед кодом
- Заготовка, вушка й ручка — окремі предмети для крафту кружки? Як вони виглядають в інвентарі (окремі іконки?)
- Кружка — це блок (ставиться на стіл), предмет у руці чи обидва?
- Чим відрізняються три варіанти (міцність, скільки вміщує, з чого крафтиться)? Що в неї наливають (молоко?).
- У `mug_wood_metal.png` є один яскраво-синій піксель — задумано чи випадково?
