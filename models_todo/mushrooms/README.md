# Текстури грибів від Fij (для Claude Code)

Намалював Fij. 16×16 PNG. Оригінал — папка «гриби» на робочому столі Fij.

| Файл | Оригінал | Що це |
|---|---|---|
| `fire_fungus.png` | `вогне_гриб/vogne_gryb.png` | вогняний гриб (помаранчево-коричнева пляма) |
| `star_fungus.png` | `зірочник/zirosznyk.png` | зірочник, зірковий гриб (жовта «зірка» з променями) |

Пов'язано з сіном: є стани сіна `star_fungus` (свіже гниле, заражене зірковим грибом) і
`fire_fungus` (сухе гниле, заражене вогняним грибом) — див. текстури сіна (`hay.zip`, README там).

- Як гриб з'являється, поширюється й що робить (корові, сіну, гравцю)?
